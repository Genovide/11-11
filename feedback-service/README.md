# Обратная связь SoundSync

POST /feedback сохраняет обращения в Cloudflare D1 без уведомлений. Telegram-бот выдаёт их владельцу по кнопке «Рассмотреть обращения». Регистрация пользователю SoundSync не нужна.

## Настройка

- Worker: soundsync-feedback. D1-база: soundsync-feedback, binding DB. Таблицы создаются при первом запросе.
- TELEGRAM_BOT_TOKEN хранится только в Cloudflare Secret.
- PAIRING_CODE — отдельный секрет одноразовой привязки владельца.
- POST /initialize с заголовком X-Setup-Code настраивает Telegram webhook на фиксированный адрес /telegram того же Worker. Секрет webhook вычисляется из токена на сервере.
- Владелец открывает бота по ссылке с одноразовым start-кодом. Его числовой ID сохраняется в config. После этого другой аккаунт привязаться не может. TELEGRAM_CHAT_ID вручную задавать не требуется.
- Адрес формы указан в app/feedback-config.json и pwa/public/feedback.js. Секретов там нет.

## Выдача обращений

Кнопка фиксирует верхнюю границу очереди и выдаёт только ещё не выданные записи до неё. До трёх записей отправляются отдельными сообщениями, большая пачка — одним UTF-8 TXT-файлом. Более поздние обращения остаются в очереди до следующего нажатия. Успешно отправленные записи отмечаются выданными. При ошибке Telegram невыданные записи сохраняются. Блокировка на две минуты предотвращает параллельную выдачу одной пачки. При аварии между подтверждением Telegram и отметкой SQL возможна повторная выдача; записи не теряются.

Входящие обращения дедуплицируются по UUID в SQL и переживают перезапуск. Новые обращения никогда не вызывают отправку в Telegram. Бот принимает команды только из личного чата привязанного владельца; webhook проверяет секрет Telegram.

## Данные и ограничения

Тема 3–120 символов, сообщение 10–3000, необязательный контакт до 160. Версия и система передаются по выбору пользователя. Музыка, любимое, история, пути и ключи не передаются. Сообщения отправляются без HTML/Markdown и предпросмотра ссылок. Ответы из Telegram автоматически в SoundSync не поступают.

Защита: проверка браузерного Origin, тело до 16 КБ, скрытое поле-ловушка, до пяти запросов за десять минут с адреса в пределах одного экземпляра. Этот счётчик не глобален и сбрасывается при перезапуске. При необходимости поддержан binding FEEDBACK_RATE_LIMITER. Текст обращений и Telegram URL с токеном не логируются кодом.

Проверки: node test.mjs и node test-queue.mjs. Тесты используют поддельный Telegram и SQLite в памяти; секреты и реальная отправка им не нужны.
