# SoundSync 1.2.2 — накопительный апдейт

Обновление прежних версий, включая 11:11. Промежуточные релизы устанавливать не требуется.

- Весь текущий код SoundSync включён в пакет: новый интерфейс, статуя, случайные треки и альбомы, история, рецензии, тексты и сортировки.
- Апдейтер проверяет компоненты установленного плеера вместо ограничения на номер предыдущей версии.
- Совместимые компоненты используются повторно. Прежний файл запуска Windows заменяется на SoundSync.exe, существующие ярлыки обновляются.
- Если движок, Python, модель или зависимости отличаются либо отсутствуют, проверенная основа докачивается автоматически с GitHub. Загруженные файлы проверяются по SHA-256.
- Музыка и Data на Windows сохраняются. На Mac данные прежней portable-версии копируются в Application Support/SoundSync, если существующего профиля SoundSync ещё нет. Исходные данные остаются в резервной копии.
- Перед заменой файлов создаётся резервная копия; установка откатывается при ошибке замены.

## Установка

Полностью закрой плеер. Распакуй нужный ZIP в отдельную папку.

**Windows x64:** запусти Update-SoundSync.bat и выбери папку своего плеера, даже если он ещё под прежним названием. После обновления запускай SoundSync.exe.

**Mac Apple Silicon:** запусти Update-SoundSync.command и выбери старое приложение. Оно станет SoundSync.app. Нужна macOS 14+. Подпись ad-hoc, без заверения Apple; ограничения Gatekeeper возможны.

Для старой или неполной установки нужен интернет: апдейтер может докачать до ~1 ГБ. Нужен запас места для временных файлов и резервной копии. Самостоятельно устанавливать полную или промежуточные версии не требуется.

Для установки с нуля остаются доступны [полные сборки 1.2.0](https://github.com/Genovide/SoundSync/releases/tag/v1.2.0); затем можно применить этот апдейт.
