# SoundSync 1.2.0

Новый выпуск под именем SoundSync: новое оформление, логотип, значки и все обновления плеера.

## Что нового

- Собственное окно рецензий РЗТ: поиск релизов, тексты, оценки и сортировка отзывов.
- Разбор названий SoundCloud: исполнитель, трек, альбом и версия записи.
- Ручное исправление данных для поиска с сохранением по ID трека.
- LRCLIB: очищенные запросы, сравнение длительности и защита от неверных таймкодов slowed/sped-up.
- Обновление названия, исполнителя и альбома из выбранного текста LRCLIB: режим «только данные», сохранение и откат.
- Бесконечная прокрутка вместо «Показать ещё».
- Сортировки библиотеки с сохранением выбранного порядка.
- Новый файл запуска SoundSync.exe и ярлыки Windows.
- Отдельная Mac-сборка с новым Electron, нативными Python и FFmpeg, встроенной моделью и журналом ошибок запуска.

## Скачать

- `SoundSync-1.2.0-Windows-x64.zip` — полная Windows x64 версия.
- `SoundSync-1.2.0-Update-Windows-x64.zip` — обновление установленной Windows версии.
- `SoundSync-1.2.0-macOS-arm64.dmg` и `.zip` — полная версия для Apple Silicon.
- `SoundSync-1.2.0-Update-macOS-arm64.zip` — обновление установленной SoundSync.app без повторного скачивания модели.
- `SHA256SUMS.txt` — контрольные суммы.

Полные версии содержат движок и модель, но не музыку, историю, настройки или ключи. Перед обновлением закрой плеер и прочитай инструкцию в архиве.

Mac: macOS 14+, Apple Silicon. Тестовая сборка с ad-hoc подписью, без нотариализации Apple; возможны ограничения Gatekeeper. Для перехода со старой неработающей Mac-сборки выбери полную версию.
