# SoundSync Pocket — SoundCloud PWA

Пробная мобильная версия SoundSync. Локальная медиатека iPhone не используется.

- Поиск треков SoundCloud внутри приложения.
- Случайная подборка SoundCloud.
- «Моя волна» по артисту, жанру и настроению: связанные записи, разнообразие артистов, исключение повторов внутри сессии.
- На iPhone отдельные треки запускаются в аудиоплеере SoundSync сразу по нажатию. На компьютере также используется собственный плеер SoundSync с hls.js.
- Обложки до 500×500 вместо маленьких превью.
- Любимое, сохранённые треки и история в localStorage; экспорт и восстановление любимого JSON-файлом.
- Установка на главный экран iPhone, офлайн-оболочка и доступ к сохранённому списку. Для музыки нужен интернет.

## Ограничения

Обнаружение треков повторяет публичный fast-path настольного SoundSync: публичные метаданные api-v2.soundcloud.com и публичный идентификатор веб-клиента. Это не официальный OAuth API приложения. SoundCloud может изменить этот механизм или ограничить доступ с адреса сервера. Если поиск перестанет работать, добавление по полной ссылке использует официальный oEmbed как резервный путь. Никаких секретов аккаунта и пользовательских cookies SoundCloud backend не получает.

Аудиопотоки не хранятся и не проксируются. На iPhone команда play выполняется непосредственно в обработчике нажатия: сервер перенаправляет запрос на доступный публичный поток SoundCloud, а Safari воспроизводит его напрямую. Заблокированные записи, превью и зашифрованные потоки не используются. Плейлисты на iPhone пока не поддерживаются этим способом. Ползунок громкости на ПК сохраняет значение. На iPhone громкость регулируется системными кнопками. Первый запуск волны после сетевого подбора может потребовать Play; прямое нажатие на уже показанный трек запускается без асинхронного ожидания. Фоновое воспроизведение зависит от Safari/iOS и SoundCloud.

Любимое внутри SoundSync не синхронизируется с аккаунтом SoundCloud или другими устройствами. Очистка данных сайта удалит локальные отметки. Первичная версия не содержит Python-синхронизацию текста.

## Разработка

Зависимостей npm нет. Node.js 22+.

- `npm run dev`: http://127.0.0.1:4187
- `npm run build`: упаковать public/ и backend в dist/server/index.js для Sites Workers.
- `npm test`: тесты списков, валидации, рекомендаций и выходного Worker.

Исходники дизайна и рекомендаций основаны на SoundSync. Библиотека hls.js 1.7.4 включена локально вместе с её лицензией Apache-2.0 в public/vendor/LICENSE. Встроенный виджет SoundCloud не используется. Музыка не включается в исходники и пакеты.

## Публикация

`npm run build` создаёт самостоятельный Cloudflare Worker в `dist/server/index.js`; статические файлы включены внутрь. Идентификаторы частного хостинга и данные доступа в исходники не включены. Для локального запуска используй `npm run dev`. Экспорт исходников не содержит музыки, настроек, любимого и истории автора.
